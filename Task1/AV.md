# Задача: 
Перенести продажу алмазов в онлайн для возвращения на рынок
# Контекст:
Из-за пандемии и ограничений оффлайн продажи резко сократились.
## сейчас
Сейчас есть оффлайн акцуион - после отбора алмазов внешние эксперты оценивают их и проводится оффлайн аукцион
## цель
Вывести процессы в онлайн:  
вместо экспертной оценки извне - оценка внутренними ресурсами и оцифровка алмазов с последующей публикацией в облаке,  
проведение аукциона в онлайне
## ограничения
Первый запуск через 2 месяца  
Целевая интеграция через год
# Оптимальное решение: 
Онлайн аукцион на сайте с личными кабинетами пользователей и автоматической отгрузкой лота победителю.
Для первого запуска аукцион можно проводить в видео конференции использую процессы существующего оффлайн аукциона. Сами данные по алмазам можно предоставить в виде excel.
Для целевого запуска нужно запустить сайт для аукциона с crm системой, которая позвоить интегрировать данные об алмазах, проводить сам аукцион и автоматизировать процессы формирования карточек и конечной продажи алмаза.
